# 📥 YouTube Downloader

<img src="https://i.ibb.co/tXCWSFm/youtube-downloader.png" alt="youtube-downloader" width="400"/>

A simple GUI application to download YouTube videos directly to your device.

---

## 🔧 Features

- 🎥 Download YouTube videos by just pasting the URL.
- 💽 Choose the best resolution automatically.
- 🖥️ Easy-to-use graphical interface using `tkinter`.
- ⚡ Fast and lightweight.

---

## 📦 Installation

Make sure you have Python 3 installed, then run:

```bash
pip3 install pytube
sudo apt install python3-tk
```

---

## 🚀 How to Run
```bash
python3 main.py
```

## 🛠️ Built With
- Python

- Tkinter (GUI)

- pytube
